The full faculty development course

Inside the OER Self-Directed Redesign course

This 14-module faculty development course guides instructors through redesigning their own courses with OER. It includes explanations, planning activities, examples and reusable resources. Work through the modules in sequence, applying each step to the course you are redesigning.

Phase 1 · Course Foundations

Modules 1–5: Define learning goals, align assessments and activities, and select instructional materials and OER.

  1. Learning Goals
  2. Assessment Strategies
  3. Learning Activities
  4. Finding and Evaluating OER
  5. Instructional Materials
Phase 2 · Course Development

Modules 6–13: Build course structure, adapt resources, and develop accessible content, assessments, interaction and instructor presence.

  1. Course Structure
  2. Customizing and Integrating OER
  3. Inclusive Classrooms
  4. Engaging Content
  5. Developing Assessments
  6. Interaction
  7. Instructor Presence
  8. A Welcoming Course
Phase 3 · Review and Refine

Module 14: Review the redesigned course against quality criteria, gather feedback and make revisions.

  1. Review & Revise

Import and adapt

  1. Download the package for your LMS.
  2. Import it into an empty test course using your LMS’s course import tool. In Brightspace, go to Course Admin → Import / Export / Copy Components → Import Components.
  3. Review the pages, resource downloads and checkpoints. Start with Getting Started in the Content area.
  4. Adapt the facilitator information, sample schedule and support arrangements for your setting.

The toolkit files above can be used independently without importing the course.

Make it work for your setting

Use the course independently, or adapt it for a facilitated faculty cohort. Both approaches follow the same 14 modules. The sample schedule and support workshop examples can help you plan local pacing and support.
