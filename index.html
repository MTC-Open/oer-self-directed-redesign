OER Self-Directed Redesign guides faculty through planning, building, and reviewing a course with open educational resources.

Developed at Midlands Technical College, this course brings the redesign process together in 14 modules, with practical tools and examples to support your own work.

When downloads are available

Get started in a few steps

Import into D2L / Brightspace

  1. Download the D2L course ZIP.
  2. Open an empty test course shell in your institution’s Brightspace site.
  3. Use Course Admin → Import / Export / Copy Components → Import Components and upload the ZIP.
  4. Review the imported Content modules, pages, files, and links before offering the course.
  5. Customize the facilitator template, schedule, and local support arrangements.

Start with Getting Started in the course’s Content area. Your institution’s menu labels may vary.

Browse without an LMS

  1. Download the browser-based course ZIP.
  2. Extract the complete ZIP into a folder on your computer.
  3. Open START-HERE.html from that extracted folder in a web browser.
  4. Keep all files and subfolders together so internal links and images work.

External readings and videos need an internet connection. Editable H5P activities need a compatible H5P host for interactive playback.

Make it work for your setting

Use the course independently, or adapt it for a facilitated faculty cohort. Both approaches follow the same 14 modules. The sample schedule and support workshop examples can help you plan local pacing and support.

AHS 102 screenshots illustrate course design choices. The AHS 102 course itself is not included for download.

Before adapting or redistributing materials, review the package’s attributions and the license or permissions attached to each resource.
